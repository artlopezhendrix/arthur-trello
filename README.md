# Arthur Trello

Kanban pessoal construído com Google Apps Script e Google Sheets.

## Stack
- Google Apps Script
- Google Sheets
- HTML / CSS / JavaScript

## Features
- Drag & drop entre colunas
- Paginação por coluna
- Auto-scroll durante o arraste
- Home com estatísticas
- Tema split (dark na home, light no quadro)

## Como rodar
1. Cria uma planilha no Google Sheets com uma aba chamada `Trello`
2. Abre Extensões → Apps Script
3. Cola `src/Code.gs` no arquivo de código
4. Cria um arquivo HTML chamado `Index` e cola `src/Index.html`
5. Substitui o ID da planilha no `Code.gs`
6. Implanta como Web App
